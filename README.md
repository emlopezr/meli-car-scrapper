MercadoLibre/TuCarro Scraper using Python and Playwright to extract car listings, specs, and images, generating detailed CSV reports for analysis.

## 📦 Usage

```bash
pip install virtualenv
py -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install
py main.py
```
